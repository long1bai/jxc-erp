## 2. 系统能力边界（明确已知）

- **技术边界**：无 HTTPS、MySQL root 无密码、无防火墙白名单——**内网小厂设计如此**；外网仅花生壳映射 8080，鉴权后未登录只见 401
- **会话机制**：token 存进程内存（SessionStore），**后端重启所有用户需重新登录**——属设计（小厂单机可接受），若在意可改持久化
- **并发上限**：Hikari 连接池默认 10，20 并发负载实测无压力；超 100 并发场景未测（实际工厂同时操作人数 <30）
- **数据量**：当前 4760 物料/3398 订单下性能良好；若订单达 10 万级需复查报表深分页（P2，暂不阻塞）

## 4. 上线/切换建议（执行顺序）

1. **补测越权**（P1，半天）→ 若通过则安全项清零
2. **全量备份**：mysqldump 当前库 + 上传图片目录 + 两份 AI 配置文件（ai_config.json/photo_config.json）
3. **通知停用 v1 录入**：8000 端口停服或只读（v1 数据已完整迁入 v2，无回迁需求）
4. **用户验收**：让员工用手机/电脑实测一周（报工打卡、拍照入库、送货、报表），问题随报随修
5. **验收通过后**：本文件归档，系统正式进入生产维护期（按 docs/09-ops.md 运维）
