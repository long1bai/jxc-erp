## 4. 长期：本地大模型 + AI 报价系统（RTX 4080 32GB 服务器）

> 现有 AI 报价/拍照识别走 DashScope（云端），规划迁到本地推理，数据不出厂。

### 4.1 总体架构

```
┌─────────────────────────────────────────────┐
│  本地服务器（RTX 4080 32GB，Windows）          │
│  ┌──────────┐  ┌──────────┐  ┌────────────┐ │
│  │ Ollama    │  │ BGE-M3   │  │ 知识库     │ │
│  │ (Qwen2.5- │  │ embedding│  │ (历史报价/  │ │
│  │ 7B/14B 4bit)│  │ 服务      │  │ 产品/工艺) │ │
│  └────┬─────┘  └────┬─────┘  └─────┬──────┘ │
│       └─────────────┼──────────────┘        │
│               ┌─────┴─────┐                 │
│               │ 推理网关    │←─ 8080 ERP 调用 │
│               │(OpenAI 兼容)│                 │
│               └───────────┘                 │
└─────────────────────────────────────────────┘
```

- **推理入口**：DashScopeClient 已支持自定义 api_url → 本地推理网关（Ollama/vLLM 的 OpenAI 兼容接口）**零改造切换**，配置改一个 URL 即可
- **embedding**：BGE-M3（bge-m3 模型，支持中英+长文本）做向量化
- **知识库**：历史报价单 + 物料表 + 工艺参数 → 向量库（本地文件/Chroma）→ RAG 问答

### 4.2 阶段排期

| 阶段 | 内容 | 交付物 | 预估 |
|---|---|---|---|
| Phase 1 | 本地推理网关搭建 + 报价助手切换本地模型 | 报价助手走本地 Qwen2.5-14B，配置切换 | 2026-09 |
| Phase 1.5 | RAG 数据问答：自然语言查库存/查报价历史 | ERP 侧栏「问数据」对话窗（只读） | 2026-09~10 |
| Phase 2 | LoRA 微调：历史报价数据微调 Qwen（LlamaFactory/Unsloth） | 报价准确率提升，学产品命名/报价策略 | 2026-10~11 |
| Phase 3 | AI 自动化嵌入：辅助报价、智能预警、自动报表草稿 | 侧栏 AI 助手全面集成 | 2026-11~12 |

### 4.3 关键决策备忘

- **成本引擎优先于纯 LLM 报价**：利润率预测用「物料成本 + 工序费 + 规则利润」确定性计算（报价技能已落地），LLM 只做需求解析/参数提取/话术生成，不做数字幻觉
- **模型选型**：Qwen2.5-7B-4bit 起步（32GB 显存可跑 14B 4bit + embedding 共存）；数据敏感度不高可先用开源
- **验证标准**：本地报价与 DashScope qwen-plus 输出做 20 条对照，准确率不低于云端才切换
- **失败回退**：配置里保留 DashScope api_url，本地不可用时一键切回（配置即切换，无需改代码）
