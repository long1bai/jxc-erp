# 功能文档（操作说明）

> 面向使用者。界面级操作说明见系统内"使用指南"（/help，Mermaid 流程图版）；本文档是各功能的详细操作步骤与注意点。

## 1. 登录与账号

- 访问 `http://<服务器IP>:5173`，admin/admin123（默认管理员）
- 角色：员工/管理员/老板/开发（系统-用户管理 里建号）
  - 员工：只看到 报工登记/拍照入库/库存查询/使用指南
  - 老板：库存/报工统计/报表/财务（只读为主，不录单）
  - 开发：基础资料/BOM/报工设置/用户/备份

## 2. 报工登记（打卡）

工人手机操作：
1. 打开 报工登记 → 选姓名 → 选工序（自动带出上次工序）
2. （选填）搜物料、写备注、改开始时间（默认现在）、拍照（最多3张）
3. 点【开始】→ 页面变计时卡（自动计时，扣午休/晚餐）
4. 完工：填完成数量 →（可选改结束时间）→ 点【结束】
5. 取消：开工后点"取消报工"（记录删除）

管理员补充：
- 报工记录 tab：按日期/分组/关键词查；点图片可预览全部；删除报工（库存回补）
- 补录报工：记录 tab 点"补录报工"→ 填员工/工序/数量/日期/起止时间（可拍照）→ 保存（自动算时长+扣料）
- 日报/月报：每人每日/每月数量+工资汇总

## 3. 拍照入库（AI 识别）

1. 菜单 拍照入库 → 拍照或选图（送货单）
2. AI 自动识别：供应商 + 单号 + 明细（名称/规格/数量/单价）
3. 核对：供应商没匹配到时手动搜索选择（或去新增）；明细可改数量/单价/删行；选入库仓库
4. 点【确认入库】→ 自动生成采购单 + 加库存 + 库存流水
- 未识别的物料自动新建（料号=名称，规格可补）

## 4. 采购入库（手工）

进销存-采购入库 → 新建 → 选供应商/日期/仓库 → 加明细（搜索物料）→ 保存（自动加库存）
- 删除采购单：库存自动回扣
- 采购退货：退货单创建扣库存；删除回补

## 5. 客户订单

进销存-客户订单 → 新建 → 选客户 → 加明细（成品）→ 保存
- 状态：待出货(pending) → 部分出货(partial) → 已出完(completed)
- 已出货的订单不可删

## 6. 送货出库

进销存-送货单 → 新建：
- **按订单出货**：选订单 → 自动带明细 → 填本次出货数量（不超剩余）→ 保存
- **临时出货**：不关联订单，直接选物料填数量
- 保存后自动扣成品库存；有 BOM 配方的自动扣组件库存；打印一式两联（客户联+存根联）
- 删除送货单：库存自动回补（已打印的记得收回纸质联）

## 7. 库存查询

- 库存查询：搜索料号/名称，看当前库存、安全库存预警（低于 min_stock 红色）
- 仓库筛选：全部仓库/指定仓（采购入库选仓后按仓查）
- 库存流水：某物料所有出入记录（来源单据、变动前后）
- BOM 配方：成品→组件 配比维护（保存=覆盖式）

## 8. 报表中心

| tab | 用途 |
|---|---|
| 月度销售 | 按月看销售（基于送货单，不是订单！） |
| 销售对账 | 选月份+客户 → 对账单（象过河样式）→ 打印 |
| 采购对账 | 供应商对账 |
| 利润分析 | 销售额 - 成本 |
| 销售查询 | 按客户/物料维度查销售 |

## 9. 财务

- 应收款：客户欠款总览（金蝶式）→ 收款单核销 → 可撤销
- 应付款：供应商欠款 → 付款单核销
- 收付款单：登记收/付款，核销对应单据
- 发票：登记开票信息

## 10. 基础资料与系统

- 客户/供应商/物料/仓库：维护名录（物料料号唯一）
- 用户管理：建号（填**姓名**，员工账号自动关联/创建报工员工→登录打卡自动带出本人）、改密、改角色（employee/admin/boss/dev）、**设分组+电话（同步报工统计/员工档案）**、禁用；**有报工记录的员工账号不能删除**（可禁用）；删除账号自动清理无记录的员工；改名自动同步员工姓名
- 数据备份：一键 mysqldump（backup/ 目录）——**重要数据记得定期备份**
- AI 报价：聊天式提问，AI 按成本+利润规则报价（不落库，可人工复制到订单）
