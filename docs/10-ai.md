# AI 文档（jxc电子 ERP v2）

> 两层含义：① 系统内集成的 AI 功能（报价助手、拍照识别、批量 BOM）——本文件；② AI 如何协作开发本项目——见项目根 `AGENTS.md`。

## 1. AI 功能总览

| 功能 | 入口 | 模型 | 后端类 | 配置 |
|---|---|---|---|---|
| AI 报价助手 | 系统菜单「AI报价」→ AiChat.vue | qwen-plus（DashScope） | `AiController` + `DashScopeClient` | `app.ai-config` → `I:\yawei-erp\ai_config.json` |
| 拍照识别入库 | 拍照入库页（手机/PC） | qwen3-vl-plus（DashScope） | `PhotoController` + `DashScopeClient` | `app.photo-config` → `I:\yawei-erp\photo_config.json` |
| AI 批量生成 BOM（v1 时代脚本） | 命令行 `batch_bom.py` | qwen-plus | —（Python v1 脚本） | `I:\yawei-erp\ai_config.json` |

**统一架构**：`DashScopeClient` 读取 JSON 配置文件（api_url / api_key / model），POST 到 OpenAI 兼容的 `/v1/chat/completions`。**密钥只存在配置文件里，不进代码、不进 git**（两文件均在 I:\ 盘，不在项目仓库内）。

## 2. AI 报价助手（/api/ai/chat）

- **前端**：`web/src/views/AiChat.vue`——聊天式交互，输入线材需求（线规/材质/长度/加工工艺），AI 输出材料费+加工费+利润报价明细（Markdown 渲染）
- **后端**：`POST /api/ai/chat`，body `{"message": "..."}` → `DashScopeClient.chat(configPath, "qwen-plus", SYSTEM_PROMPT, message)` → 返回 `{"reply": "..."}`
- **系统提示词**：`AiController.SYSTEM_PROMPT`（Java 21 文本块）——内置jxc产品线（线材/端子/组装/后焊/太阳能线材）报价口径
- **配置**：`application.yml` → `app.ai-config: I:\yawei-erp\ai_config.json`（结构：`{"api_url": "...", "api_key": "..."}`）

## 3. 拍照识别入库（/api/photo）

- **流程**：手机/PC 拍照 → 上传 → qwen3-vl-plus 识别（结构化 JSON：供应商/物料/数量/单价）→ 自动匹配供应商与物料 → 可编辑确认 → 生成入库单
- **接口**：`POST /api/photo/*`（上传/确认），`PhotoController` 调 `dash.chat(photoConfigPath, "qwen3-vl-plus", "你是送货单识别专家。", content)`，`temperature: 0.05` 保精度
- **配置**：`app.photo-config: I:\yawei-erp\photo_config.json`（vision 前缀字段：`vision_api_url` / `vision_api_key` / `vision_model`，DashScopeClient 兼容两种前缀）
- **模型选择实测**（2026-07-25 验证）：
  - `qwen3-vl-plus` ⭐ 日常推荐：3~5s 快，多行表格 2/2，数量偶错需人改
  - `qwen3.7-max` 手写识别强但 20~80s 太慢
  - SiliconFlow `Qwen3-VL-32B-Instruct` 备选（编码最精确）
  - 复杂表格（列内容重复/大量空行）所有模型都会出错 → 页面允许全字段人工修正

## 4. 批量 BOM 生成（batch_bom.py，v1 脚本）

- 位置：`I:\yawei-erp\batch_bom.py`（Python v1 环境，uv venv）
- 用途：587+ 成品批量配置 BOM——从产品名提取关键词（线规/连接器类型）→ 过滤候选原材料 → AI 在候选池选 component_id → 写 bom_items
- 准确率约 60-70%，需人工复核。配方细节：技能 `yawei-erp-system` references/batch-bom-ai.md

## 5. 密钥与配置维护

> 2026-08-02：配置路径迁到 `yawei-erp-config/`，且**支持管理员在界面改**（系统 → 系统配置 → AI 配置），也可直接改文件。

```bash
# 配置文件位置（不在 git 仓库内，注意备份！）
yawei-erp-config\ai_config.json       # 报价助手：api_url / api_key / chat_model / vision_model / system_prompt
yawei-erp-config\photo_config.json    # 拍照识别：vision_api_url / vision_api_key / vision_model

# 切换模型/供应商：改配置里的 model / api_url / api_key 即可，无需改代码
# （DashScopeClient 每次调用都读配置，改完立即生效，无需重启后端）
```

**可配置字段（2026-08-02 起）**：
- `chat_model`：报价对话模型（缺省回退代码默认 qwen-plus）
- `vision_model`：拍照识别视觉模型（缺省回退代码默认 qwen3-vl-plus）
- `system_prompt`：报价提示词模板，支持 `{company_name}` 占位符（由 sys_config.company_name 填充）
- 换 AI 供应商 = 改 `api_url` + `api_key` + 模型名，**不改代码**

**备份提醒**：两配置文件含 API Key，容灾备份（dr_backup.py 的 config/ 目录）已自动包含它们；db_secret.env（数据库密码）同样被备份覆盖。

## 7. 排障

| 症状 | 原因 | 处理 |
|---|---|---|
| 报价/拍照报"配置文件缺少 API Key" | ai_config.json / photo_config.json 缺失或字段名不对 | 检查两文件存在 + api_key 字段 |
| 识别超时/慢 | 模型选错（3.7-max 20-80s） | 换回 qwen3-vl-plus |
| 识别结果乱 | 表格复杂（列重复/空行） | 页面手动修正；或临时切 SiliconFlow 32B |
| qwen2.5-vl-72b 403 | 该模型未在 DashScope 控制台开通 | 用已开通模型（qwen3-vl-plus 等） |
