# 产品文档（工厂生产经营一体化管理系统）

> 小型工厂生产经营一体化管理系统（进销存 + 生产报工 + 财务，轻量 ERP）。部署环境：（公司地址）。电话：（联系电话）（（联系人））。

## 1. 系统定位

小厂内部业务系统（非 SaaS），覆盖 **进（采购）→ 产（报工）→ 销（出货）→ 财（应收应付）** 全流程：

- 采购入库（含拍照 AI 识别入库）、库存管理（含仓库维度）、报工打卡（含自动扣料）、客户订单、送货出库（含 BOM 自动扣组件）、报表对账、应收/应付核销、AI 报价助手

前端 PC 端 + 手机端（工人用手机打卡/拍照），无需安装，浏览器访问。

## 3. 核心业务流程

### 3.1 进：采购入库
```
供应商送货 → 拍照入库(AI识别) 或 手工采购入库 → 选仓库 → 自动加库存 + 库存流水 → 应付挂账
```

### 3.2 产：报工（打卡式）
```
工人手机：选姓名 → 选工序 → (拍照/物料/备注) → 开始 → 完工填数量 → 结束
→ 自动算时长(扣午休/晚餐) + 自动扣工序物料库存 + 计件工资(工序单价×数量)
```

### 3.3 销：出货
```
客户下单(客户订单) → 生产完成 → 送货单(按订单出货/临时出货) → 打印一式两联 → 客户签收
→ 自动扣成品库存 + 有 BOM 配方时自动扣组件库存 → 订单状态回写(部分/结清)
```

### 3.4 财：对账收款
```
月底 → 报表中心-销售对账(按月/客户) → 打印对账单 → 收款单核销应收 / 付款单核销应付
```

## 5. 关键业务口径（重要，改代码前先读）

1. **月度销售报表基于 delivery_notes + delivery_items（送货单）**，不是 customer_orders；历史订单需生成送货单才能进报表
2. **仪表盘"待处理订单数" = pending + partial 合并**（卡片 sub 显示"未出X/部分Y"）
3. **出货规则**：按订单出货不能超量（可出 = 订购 - 已出）；临时出货不关联订单不受限。历史超量：≤5 备注"含备品"，>5 备注"超量需核实"
4. **报工时长**：自动扣除午休 12:00-13:00、晚餐 17:30-18:00（前后端同一规则）
5. **报工扣料**：process_materials（工序×物料×单耗）× 数量 → stock_movements 流水，备注"报工扣料#员工-工序"
6. **送货单删除**：库存自动回补（流水随删回补）；已打印的注意收回纸质联
7. **采购入库/拍照入库**：自动加库存 + 流水；删除采购单自动回扣库存
8. **BOM**：成品出库时按配方自动扣组件库存（bom_items），组件库存不足不拦截（记录流水为负）
9. **仓库**：采购入库可选仓；送货出库/报工扣料目前从 1 号仓扣（未按仓出库）
10. **工资** = 工序单价(processes.unit_price) × 报工数量，不区分加班
11. **对账单**：象过河样式（客户/供应商），底部"5 日内回传"
12. **账号角色**：员工/管理员/老板/开发，菜单级权限

## 6. 非功能约定

- 小厂内网使用，不考虑安全（后端无细粒度鉴权）
- 手机端优先（工人打卡/拍照），PC 端管理
- 数据备份：系统页"数据备份"（mysqldump 到 backup/ 目录），重要数据定期手动备份
